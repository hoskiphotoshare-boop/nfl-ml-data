Privacy & analytics

Short version: no cookies, no accounts, no IP addresses, no cross-site tracking.

What is counted

The site records aggregate, first-party usage so the admin can see which pages, tabs and features are used:

  • the page path (for example /teams/KC),
  • event names and short labels: tab loads, Schedule/Edges/Results views, game-card opens, player opens, team links, filter and sort changes, theme toggles,
  • the referrer hostname (not its path or query),
  • the country, device class, browser family and operating-system family (derived from the request; the raw user agent is not stored),
  • a visitor value: a daily-salted SHA-256 hash of your IP address and user agent, truncated to 64 bits.

The raw IP address and user agent are never written to storage, and the visitor value changes every UTC day, so it cannot be used to follow you across days or sites.

What is not collected

No cookies, no login, no advertising identifiers, no precise location, no cross-site pixels, and no third-party analytics script. The browser only calls this site's own /api/analytics/collect endpoint.

Retention

Raw event batches expire after 365 days. The admin only reads aggregate counts; individual batches are not shown in the UI.

Opting out

Collection is disabled automatically when your browser sends Do Not Track or Global Privacy Control. You can also disable it for this browser by running this in the console:

localStorage.setItem('nfl_no_analytics', '1')

To turn it back on: localStorage.removeItem('nfl_no_analytics').
